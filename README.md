# Nemos

Nemos, kullanıcıya birkaç seçim adımı gösterip sonunda ona hazır bir HTML oyun fikri sunacak mobil uygulamanın başlangıç iskeletidir.

## Bu sürümde neler var?

- Expo + React Native + TypeScript başlangıç yapısı
- 4 adımlı seçim akışı
- 20 oyunluk konsept kütüphanesi
- Kullanıcı seçimlerine göre en uygun oyunu öneren eşleme fonksiyonu
- İleride HTML oyunları WebView ile gösterilecek sonuç ekranı taslağı

## Kurulum

```bash
npm install
npm run start
```

## Sonraki adımlar

1. Her oyun için HTML çıktı paketini ayrı bir içerik formatına bağlamak
2. WebView ekranı ve oyun yükleme altyapısını eklemek
3. Uzaktan çok oyunculu oyunlar için lobby / room servis tasarımı hazırlamak
4. Admin panel veya içerik editörü ile bu 20 oyunluk havuzu yönetilebilir hale getirmek
